SUBIR A GITHUB
1. Descargá el ZIP y extraélo.
2. Abrí https://github.com/pablobritez245-boop/invitacion-juan-manuel
3. En la rama `main`, elegí Add file > Upload files.
4. Arrastrá los archivos y carpetas de esta versión, incluida la carpeta `assets` completa.
5. Verificá que `assets/musica-original.mp3` se suba junto con el resto.
6. Aceptá reemplazar los archivos existentes y confirmá el commit en `main`.
7. Cloudflare Pages debería publicar automáticamente cuando finalice el despliegue.
8. Probá el mismo enlace: https://invitacion-juan-manuel.pages.dev

IMPORTANTE
- No cambies el nombre del proyecto ni la configuración de Cloudflare.
- No elimines ni renombres `assets/musica-original.mp3`; el botón depende de esa ruta.
- El mismo enlace sirve para Samsung, iPhone, Chrome y computadora.
- La música comienza únicamente cuando el invitado pulsa el botón, por las restricciones de reproducción automática de los navegadores.
