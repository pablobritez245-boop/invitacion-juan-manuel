SUBIR A GITHUB (DESDE EL NAVEGADOR)
1. Descargá el ZIP y extraélo.
2. Abrí https://github.com/pablobritez245-boop/invitacion-juan-manuel
3. En la rama main, elegí Add file > Upload files.
4. Arrastrá index.html, styles.css, script.js, README.md y .nojekyll, además de la carpeta assets completa.
5. Aceptá reemplazar los archivos existentes y confirmá el commit en main.
6. Esperá a que Cloudflare Pages termine el despliegue automático.
7. Probá el mismo enlace: https://invitacion-juan-manuel.pages.dev
